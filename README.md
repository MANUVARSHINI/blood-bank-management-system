# 🩸 Blood Bank Management System

## 📌 Project Overview

The **Blood Bank Management System** is a database-based project developed to manage blood bank operations efficiently. It maintains donor details, blood donation records, and other essential information required for blood bank management.

This project demonstrates the implementation of database concepts using SQL and PL/SQL in Oracle Database.

## 🎯 Objectives

- Maintain donor information.
- Manage blood donation records.
- Organise blood group details.
- Perform database operations efficiently.
- Implement SQL and PL/SQL concepts for database management.

## 🛠️ Technologies Used

- Oracle SQL
- Oracle PL/SQL
- Oracle Live SQL

## 📚 Project Implementations

The initial version of the project was developed using Oracle SQL.

The updated version extends the database project using Oracle PL/SQL programming concepts.

It includes the PL/SQL features implemented in the updated code, such as:
- PL/SQL blocks

- Cursors and triggers (where implemented)

## ▶️ How to Run

4. Copy the code into the SQL Worksheet.
